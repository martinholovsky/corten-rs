## MITRE's language tags are not a measure

Each CWE lists the languages it applies to (`Applicable_Platforms`). Counting a CWE for a language when that list names the language, or a class it belongs to, gives the numbers below. They disagree with the per-CWE review in both directions: the tags record where a weakness has been documented, not what a language allows. Most of the over-count is hardware, physical and process weaknesses tagged *Not Language-Specific*.

| Language | Tags count it for | Audited writable | Tagged, not writable | Writable, not tagged |
| --- | ---: | ---: | ---: | ---: |
| C (C, Compiled, Memory-Unsafe, Not Language-Specific) | 838 | 789 | 90 | 41 |
| C++ (C++, Compiled, Memory-Unsafe, Not Language-Specific, Object-Oriented) | 847 | 795 | 87 | 35 |
| Java (Java, Not Language-Specific, Object-Oriented) | 841 | 831 | 87 | 77 |
| Go (Compiled, Go, Not Language-Specific) | 764 | 790 | 89 | 115 |
| Python (Interpreted, Not Language-Specific, Object-Oriented, Python) | 778 | 802 | 86 | 110 |
| Rust (Compiled, Not Language-Specific, Rust) | 763 | 787 | 91 | 115 |

The Phase 0 ledger counted 853 for Rust from the same tags plus 46 judgement calls; the rule here is mechanical, so the two differ.
