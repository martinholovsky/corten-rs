# CWE applicability to C++

Generated by `scripts/language-docs.py` from `audit/languages/cpp/rows.csv`; do not edit by hand.

For each of the 944 weaknesses in MITRE CWE 4.20: can a C++ program contain it? Each row is read the way the Rust row for the same CWE is read ([`rust-applicability.md`](rust-applicability.md)), so the two can be compared. Where the language or compiler decides, a program in `audit/languages/cpp/` shows it, and `scripts/language-check.sh cpp` re-checks every program against g++ 15.3.0, -std=c++20 -pedantic-errors. A compiling program shows the weakness can be written; whether it exhibits the weakness is the judgement stated in its comment.
